# 24. F03. 사용자 여정·IA·와이어프레임·요구사항 — 미션 예시

> 문서 미션: F03-1·F03-3 의 표는 마크다운 문서로, F03-2·F03-3 의 그림은 Figma/FigJam 으로 제출해요. 로그인·결제·개인정보 화면은 그리지 않아요.

## 배우기 재료
- 핵심 개념
  - **페르소나와 여정 지도**: 페르소나는 리서치에서 나온 대표 사용자 한 명(지어낸 이름, 내용은 근거 있는 사실)이고, 여정 지도는 가로가 시간(단계), 세로가 행동·생각·감정·기회인 표예요. 감정이 가장 낮은 칸이 고칠 곳이에요.
  - **사이트맵과 유저 플로우**: 사이트맵은 "어떤 방이 있나"(화면 목록의 가계도), 유저 플로우는 "어떤 길로 다니나"(갈림길 포함 화살표)예요. 화면이 바뀌지 않는 기능(걸러 보기 등)은 사이트맵 상자가 아니에요.
  - **와이어프레임**: 색·사진 없이 회색 상자로 자리만 잡은 연필 스케치예요. 같은 화면을 375 · 768 · 1280 으로 그려 열 수가 1 · 2 · 3 으로 바뀌는 것을 보여요(W14 의 640/1024 경계와 같은 생각).
- 작은 따라 하기 (사이트와 상관없이 직접 그려요)
  ```text
  1. 프레임(F) W 375, H 600 → 이름 wf-demo → Shift + A (Vertical, Padding 16, Gap 16)
  2. 글자 header, search, list 를 쓰고 각각 Shift + A 로 프레임에 감싸기
  3. 회색(D9D9D9) 사각형을 list 안에 넣고 가운데에 글자 IMG
  4. Ctrl + D 로 복제 → 이름 wf-demo-wide, W 768
  5. list 방향을 Horizontal + Wrap 으로 바꾸기
  ```
- 예상해 보기: 5번에서 Wrap 을 끄면 list 안의 상자들은 어떻게 될까요? — 답: 줄을 바꾸지 않고 한 줄로 늘어서다가 프레임 밖으로 나가요(CSS 에서 `flex-wrap` 을 안 쓴 것과 같아요).
- 공식 문서: [Frames in Figma Design (Figma)](https://help.figma.com/hc/en-us/articles/360041539473-Frames-in-Figma-Design) · [Guide to auto layout (Figma)](https://help.figma.com/hc/en-us/articles/360040451373-Guide-to-auto-layout)

## 원본 닮음
미션마다 완료 기준 끝에 "원본 닮음" 기준을 하나 더한다. 튜터가 고른 사이트를 같은 폭으로 열어 아래 항목의 **원본 값**(칸 수·순서·자리·DevTools로 읽은 값)을 넣어 구체적으로 만든다. 사진·글은 원본 것을 쓰지 않으므로 비교하지 않는다.
- F03-1: 해당 없음 (페르소나·여정)
- F03-2: `userflow` 단계가 서비스 지도의 흐름(`site.flows`) 단계와 같음, `sitemap` 1단계가 원본 주 메뉴와 같음
- F03-3: 세 폭 와이어프레임의 칸 수·구역 순서가 원본 세 폭 화면과 같음

## 힌트 재료
- 1단계: Figma 도움말 "Frames in Figma Design" — https://help.figma.com/hc/en-us/articles/360041539473-Frames-in-Figma-Design , 요소가 줄 바꿈하는 설정은 "Guide to auto layout" 의 Wrap — https://help.figma.com/hc/en-us/articles/360040451373-Guide-to-auto-layout
- 2단계: ① 페르소나 칸마다 "근거: P번호"를 한 줄 달기 ② 사이트맵은 화면마다 상자(`node-…`)를 만들고 위치를 다 정한 뒤 마지막에 화살표 긋기 ③ 와이어프레임은 모바일을 먼저 그린 뒤 복제해 폭을 바꾸고, 목록 프레임의 방향을 Horizontal + Wrap 으로 바꿔 열 수 맞추기 ④ 요구사항은 "○○가 보인다"처럼 확인할 수 있는 문장으로
- 3단계 예시(다른 주제):
  ```text
  | ID     | 기능      | 설명(완료 기준)                  | 우선순위 |
  | REQ-01 | 목록 보기 | 카드 6개에 사진·이름·날짜가 보인다 | 필수     |
  | REQ-02 | 빈 결과   | 결과가 0개면 안내 문구가 보인다    | 필수     |
  ```

## 자주 막히는 곳
- 화살표가 상자를 옮기면 따라오지 않음 → Figma Design 의 화살표는 그런 도구예요. 상자 위치를 다 정한 뒤 마지막에 그어요(따라오는 연결선이 필요하면 FigJam)
- 와이어프레임 세 프레임의 구역 순서가 다름 → 복제해서 만들면 순서가 같아요. 새로 그리지 말고 `Ctrl + D` 로 복제해요
- 요구사항 설명이 "보기 좋게" 같은 말 → 확인할 수 있는 문장("카드에 사진·이름·가격이 보인다")으로 바꿔요
