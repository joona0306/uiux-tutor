# 10. W10. Flexbox ① 방향·간격·정렬 — 미션 예시

## 배우기 재료
- 핵심 개념
  - **flex 는 부모에**: `display: flex` 를 **줄 세우고 싶은 요소들의 부모**에 줘요. 자식들이 가로 한 줄로 서요. `flex-direction: column` 이면 세로예요. Figma Auto Layout 의 Direction(Horizontal/Vertical)과 같아요.
  - **gap 과 정렬**: `gap` 은 아이템 사이 간격(Auto Layout 의 Gap). `justify-content` 는 **주축**(가로 방향이면 가로), `align-items` 는 **교차축**을 정렬해요(Space between ↔ `space-between`, 정렬 상자 ↔ 두 속성의 조합).
  - **설정표 옮기기**: Auto Layout 의 방향·Gap·Padding·정렬 네 항목이 flex 의 `flex-direction` · `gap` · `padding` · `justify-content` + `align-items` 에 대응해요.
- 작은 따라 치기 (사이트와 상관없이 직접 쳐요)
  ```html
  <div class="row"><span>로고</span><a href="#">메뉴</a></div>
  ```
  ```css
  .row {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 16px;
    padding: 12px 16px;
  }
  ```
  DevTools Elements 에서 `.row` 옆의 `flex` 배지를 눌러 오버레이를 켜 봐요.
- 예상해 보기: `.row` 에 `flex-direction: column` 을 더하면 `justify-content: space-between` 은 가로·세로 중 어느 방향 간격을 벌릴까요? — 답: 세로예요. 주축이 세로로 바뀌어서 `justify-content` 가 세로 방향을 맡아요(높이가 내용만큼이면 눈에 안 띌 수 있어요).
- 공식 문서: [Flexbox (MDN)](https://developer.mozilla.org/ko/docs/Learn_web_development/Core/CSS_layout/Flexbox) · [gap (MDN)](https://developer.mozilla.org/ko/docs/Web/CSS/gap)

| 미션 | 할 일 (고른 사이트의 구역에 맞춰 바꿔요) | 완료 기준 |
|---|---|---|
| W10-1 기본 구조 | 고른 사이트의 머리글(로고 왼쪽, 메뉴 오른쪽)을 flex 로 정렬해요 | `display: flex` 가 머리글 **부모**에 있음 / `justify-content: space-between` 와 `align-items: center` / 로고와 메뉴가 가로 한 줄에 양 끝으로 놓임 |
| W10-2 개념 적용 | 고른 사이트의 목록 카드 한 장 안(카테고리·이름·가격)을 세로로 쌓고 간격을 `gap` 으로 줘요. 메뉴 링크 3개는 가로로 놓고 `gap` 으로 띄워요 | 카드 안쪽에 `flex-direction: column` 과 `gap` / 메뉴 링크 부모에 `display: flex` 와 `gap` / 아이템 사이 간격을 `margin` 이 아니라 `gap` 으로 줌 |
| W10-3 응용 | 고른 사이트의 가로로 긴 구역(가격 줄이나 알림 배너) 하나를 골라, 직접 정한 Auto Layout 설정표(방향·Gap·Padding·정렬)를 먼저 적고 같은 모양의 CSS 로 옮겨요 | 설정표 네 항목이 CSS 값과 하나씩 대응함 / `justify-content` 와 `align-items` 를 주축·교차축으로 구분해 설명함 / DevTools `flex` 배지 오버레이로 확인함 |

## 힌트 재료
- 1단계: MDN Flexbox·`gap` 문서(위 링크)
- 2단계: 먼저 "어느 요소들을 한 줄에 세울까?"를 정하고 그 요소들의 **부모**에 `display: flex` 를 써요. 세로 쌓기는 `flex-direction: column`. 가로 가운데는 방향에 따라 `justify-content`(주축) 또는 `align-items`(교차축) 예요.
- 3단계 예시(다른 이름·다른 값):
  ```css
  .toolbar { display: flex; align-items: center; justify-content: space-between; gap: 8px; padding: 8px 12px; }
  .info { display: flex; flex-direction: column; gap: 4px; }
  ```

## 자주 막히는 곳
- 상자들이 여전히 위아래로 쌓임 → `display: flex` 를 자식에 썼어요(부모에 써야 해요)
- `gap` 을 썼는데 간격이 없음 → 같은 규칙에 `display: flex`(또는 grid)가 없음
- `align-items: center` 인데 세로 가운데로 안 감 → 부모 높이가 내용만큼이라 움직일 공간이 없음
