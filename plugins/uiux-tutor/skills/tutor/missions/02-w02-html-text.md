# 02. W02. HTML 문서 구조와 텍스트 — 미션 예시

## 배우기 재료
- 핵심 개념
  - **문서 뼈대**: `<!DOCTYPE html>` → `<html lang="ko">` → `<head>`(탭 이름·글자 방식 같은 정보) → `<body>`(화면에 보이는 내용). 화면에 안 보이는 정보는 head, 보이는 건 body예요.
  - **제목은 크기가 아니라 단계**: `<h1>` 하나, 그 아래 `<h2>`, 그 아래 `<h3>`. Figma에서 프레임 안에 프레임을 중첩하는 것처럼 글의 목차 구조를 만들어요. 글자 크기를 키우려고 고르지 않아요.
  - **문단과 강조·줄바꿈**: 문단은 `<p>`, 중요한 말은 `<strong>`, 강조는 `<em>`. `<br>`(줄바꿈)·`<hr>`(구분선)은 닫는 태그가 없어요.
- 작은 따라 치기 (사이트와 상관없이 직접 쳐요)
  ```html
  <h1>우리 동네 빵집</h1>
  <h2>오늘의 빵</h2>
  <p>갓 구운 <strong>소금빵</strong>은 오전 10시에 나와요.</p>
  <hr>
  <h2>가게 정보</h2>
  <p>서울시 어딘가<br>매주 월요일 휴무</p>
  <!-- 주소는 나중에 진짜로 고치기 -->
  ```
  `Ctrl + /` 로 주석을, `Shift + Alt + F` 로 들여쓰기 정리를 해 봐요.
- 예상해 보기: `<h2>오늘의 빵</h2>` 을 `<h4>오늘의 빵</h4>` 로 바꾸면 화면 글자는 어떻게 되고, 무엇이 문제일까요? — 답: 글자는 작아지지만 눈에 보이는 건 그뿐이고, 제목 단계를 건너뛰어 글의 목차 구조가 깨져요(스크린 리더 사용자가 구조를 따라가기 어려워져요).
- 공식 문서: [제목 요소 h1~h6 (MDN)](https://developer.mozilla.org/ko/docs/Web/HTML/Reference/Elements/Heading_Elements) · [HTML 기본 문법 (MDN)](https://developer.mozilla.org/ko/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax)

| 미션 | 할 일 (고른 사이트의 구역에 맞춰 바꿔요) | 완료 기준 |
|---|---|---|
| W02-1 기본 구조 | 새 파일 `text.html` 에 문서 뼈대를 **보지 않고** 쳐요. 고른 사이트의 소개 구역(예: "이 서비스는 …")을 내 말로 바꿔 `<h1>` 과 `<p>` 로 써요 | `<!DOCTYPE html>` 부터 `</html>` 까지 짝이 맞음 / `lang="ko"` · `charset="UTF-8"` · `viewport` · `<title>` 이 모두 있음 / `<h1>` 이 한 개 |
| W02-2 개념 적용 | 고른 사이트의 안내 글 구역(공지·이용 안내·소개 글 등)을 목차 구조로 옮겨요. 큰 제목 아래 작은 제목 두 개, 각각 문단을 달아요 | `<h1>` → `<h2>` → `<h3>` 순서로 건너뛰지 않음 / 제목마다 `<p>` 문단이 하나 이상 / 제목을 고른 이유가 "크기"가 아니라 "단계"라고 말할 수 있음 |
| W02-3 응용 | 문단 안의 중요한 말에 `<strong>`, 줄바꿈이 필요한 곳(주소·운영 시간)에 `<br>`, 큰 주제가 바뀌는 곳에 `<hr>`, 코드 맨 아래에 할 일 주석을 남겨요 | `<strong>` · `<br>` · `<hr>` 를 각각 한 번 이상 씀(`<br>` · `<hr>` 에 닫는 태그 없음) / 주석 `<!-- … -->` 이 한 개 이상 / `Shift + Alt + F` 로 들여쓰기를 정리함 |

## 원본 닮음
미션마다 완료 기준 끝에 "원본 닮음" 기준을 하나 더한다. 튜터가 고른 사이트를 같은 폭으로 열어 아래 항목의 **원본 값**(칸 수·순서·자리·DevTools로 읽은 값)을 넣어 구체적으로 만든다. 사진·글은 원본 것을 쓰지 않으므로 비교하지 않는다.
- W02-1: 소개 구역의 글 순서(제목 → 문단)가 원본과 같음
- W02-2: 제목 단계와 문단 수 구성이 원본 안내 글 구역과 같음
- W02-3: 해당 없음 (글 꾸밈 태그)

## 힌트 재료
- 1단계: 제목 요소 문서와 HTML 기본 문법 — 위 공식 문서 두 개
- 2단계: 뼈대는 위에서 `DOCTYPE → html → head(meta·title) → body` 순서예요. 제목 단계는 "이 글의 목차를 종이에 먼저 적고" 그 단계대로 번호를 달아요. 줄바꿈이 필요한 한 문단은 `<p>` 하나 안에 `<br>` 으로 나눠요.
- 3단계 예시(다른 이름·다른 값):
  ```html
  <h1>요가 스튜디오 안내</h1>
  <h2>수업 시간</h2>
  <h3>평일</h3>
  <p>오전 <strong>7시</strong>, 저녁 8시<br>(일요일 휴무)</p>
  ```

## 자주 막히는 곳
- 아래 글자가 전부 굵게·크게 보임 → `</strong>`·`</h2>` 같은 닫는 태그가 빠짐(오류 메시지는 안 나와요). F12 → Elements 로 구조를 확인해요
- 코드에서 줄을 바꿨는데 화면은 한 줄 → HTML은 코드 줄바꿈을 띄어쓰기 한 칸으로 봐요. 문단은 `<p>`, 문단 안 줄바꿈은 `<br>`
- 탭 이름이 주소처럼 나옴 → `<head>` 안 `<title>` 이 없거나 철자 오타
