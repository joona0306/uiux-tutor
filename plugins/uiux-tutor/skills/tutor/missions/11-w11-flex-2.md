# 11. W11. Flexbox ② 늘이기·줄이기·줄바꿈, 레이아웃 실습 — 미션 예시

## 배우기 재료
- 핵심 개념
  - **줄바꿈**: `flex-wrap: wrap` 은 **부모**에 써요. 아이템이 한 줄에 다 안 들어가면 다음 줄로 넘어가요.
  - **늘이기·줄이기·시작 크기**: 아이템에 `flex-grow`(남는 공간을 나눠 갖는 정도, 기본 0) · `flex-shrink`(모자랄 때 줄어드는 정도, 기본 1) · `flex-basis`(시작 크기). 줄임말 `flex: 1` 은 "남는 공간을 똑같이 나눠 가져요"라는 뜻이에요.
  - **Hug·Fill·Fixed**: Figma Auto Layout 의 Hug(내용만큼)는 flex 기본, Fill(꽉 채우기)은 `flex: 1`, Fixed(고정)는 `flex: 0 0 크기` 예요. 안 줄어들어 가로 스크롤이 생기면 `min-width: 0` 을 떠올려요.
- 작은 따라 치기 (사이트와 상관없이 직접 쳐요. `.photo`, `.text` 두 상자를 `.item` 안에 넣어요)
  ```css
  .item { display: flex; gap: 16px; flex-wrap: wrap; }
  .photo { flex: 0 0 120px; height: 90px; background: #cbd5e1; }
  .text { flex: 1 1 200px; }
  ```
- 예상해 보기: 위 `.photo` 의 `flex: 0 0 120px` 를 `width: 120px` 로 바꾸면(공간이 모자란 좁은 화면에서) 어떻게 될까요? — 답: `flex-shrink` 기본값이 1이라 공간이 모자라면 120px 보다 좁아져요. `0 0 120px` 는 줄어들지 않게 고정해요.
- 공식 문서: [flex (MDN)](https://developer.mozilla.org/ko/docs/Web/CSS/flex) · [flex-wrap (MDN)](https://developer.mozilla.org/ko/docs/Web/CSS/flex-wrap)

| 미션 | 할 일 (고른 사이트의 구역에 맞춰 바꿔요) | 완료 기준 |
|---|---|---|
| W11-1 기본 구조 | 고른 사이트의 상세 구역(큰 사진 + 설명 묶음)을 가로로 놓고, 사진은 Fixed(고정), 설명은 Fill(남는 공간)으로 만들어요 | 사진에 `flex: 0 0 값px` / 설명에 `flex: 1` 계열 / 부모에 `display: flex` 와 `gap` |
| W11-2 개념 적용 | 같은 구역이 좁은 화면에서 설명이 사진 아래로 내려가게 해요. 태그(칩) 목록은 넘치면 다음 줄로 넘기고 | 부모에 `flex-wrap: wrap` / 설명의 시작 크기를 `flex: 1 1 280px` 처럼 정함 / 창 폭을 줄이면 설명이 아래로 내려옴 / 태그 목록 부모에 `flex-wrap: wrap` |
| W11-3 응용 | 고른 사이트의 머리글 + 목록 구역을 완성해요: 입력창이 있는 줄에서 입력은 Fill, 버튼은 Hug 로 하고, 안 줄어드는 아이템이 있으면 `min-width: 0` 으로 풀어요 | 입력칸에 `flex: 1`, 버튼은 `flex` 설정 없음(내용만큼) / 375px 에서 가로 스크롤 없음 / `flex: 1` 과 `flex-grow: 1` 의 차이를 한 문장으로 말함(시작 크기 0% 와 auto) |

## 힌트 재료
- 1단계: MDN `flex`·`flex-wrap` 문서(위 링크)
- 2단계: `flex-wrap` 은 부모에, 나머지는 아이템에 써요. "안 들어간다"가 생기려면 아이템에 시작 크기(`flex-basis` 또는 `width`)가 있어야 해요. 고정 크기는 `flex: 0 0 크기`.
- 3단계 예시(다른 이름·다른 값):
  ```css
  .layout { display: flex; flex-wrap: wrap; gap: 24px; }
  .sidebar { flex: 0 0 240px; }
  .content { flex: 1 1 320px; min-width: 0; }
  ```

## 자주 막히는 곳
- `flex-wrap: wrap` 을 썼는데 줄바꿈이 안 됨 → 자식에 썼거나, 아이템이 `flex: 1`(시작 크기 0)이라 한 줄에 다 들어감
- `width: 220px` 를 줬는데 카드가 더 좁아짐 → 기본 `flex-shrink: 1`(고정은 `flex: 0 0 220px`)
- 안 줄어들고 화면 밖으로 삐져나옴(가로 스크롤) → 아이템의 기본 최소 너비 때문(`min-width: 0`)
