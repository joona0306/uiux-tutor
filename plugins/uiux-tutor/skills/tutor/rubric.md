# 평가 형식 ("다음"을 불렀을 때)

```
### 미션 W13-2 평가 — 시도 2번째

| 완료 기준 | 판정 | 근거 |
|---|---|---|
| 375px 1열 · 640px 2열 · 1024px 3열 | ✅ | style.css:41–52, 세 폭에서 열 수 확인 |
| `@media (width >= 640px)` 모양 | 🔧 | style.css:45 `min-width: 640px` — 같은 뜻이지만 수업 표기는 `width >=` |
| 간격은 gap | ✅ | style.css:43 `gap: 16px` |

잘한 점: 카드 안 구조를 article로 묶어 시맨틱하게 만들었어요.
보완할 점: 45번 줄 미디어쿼리 표기를 바꿔 주세요.
추가 과제(5분): 1024px 이상에서 4열로 바꿔 보고 다시 3열로 돌려 두세요.

보완하고 다시 "다음"을 불러 주세요.
```

## 판정 기준
- ✅ 통과: 기준을 만족하고 근거(파일:줄 또는 실행 결과)가 있다.
- 🔧 보완: 기준을 못 맞췄거나, 맞췄는지 **확인할 수 없다**. 확인할 수 없으면 무엇을 보여 주면 되는지 말한다(예: "브라우저 폭 640px 화면 캡처").
- 미션과 상관없는 다른 문제는 판정에 넣지 않고 "덧붙임"으로 한 줄만 적는다.

## 말투
- 고칠 곳은 **위치와 이유**까지만. 고친 코드는 주지 않는다(학습자가 "정답 보여 줘"라고 할 때만).
- 한 번에 보완할 점은 3개 이하. 많으면 가장 중요한 것부터.
- 시도가 3번을 넘으면 개념 설명을 한 번 더 하고, 미션을 두 조각으로 나눠 준다.
